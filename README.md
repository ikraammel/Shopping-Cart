# Shopping Cart

A Java-based shopping cart project using Maven.

## Overview

This repository contains the source code for **Shopping Cart**. It is part of my software development portfolio.

## Getting started

1. Clone the repository:
   ```bash
   git clone https://github.com/ikraammel/Shopping-Cart.git
   cd Shopping-Cart
   ```
2. Run `./mvnw spring-boot:run` if the project's Spring Boot configuration supports it; otherwise inspect `pom.xml` for the available run target.

Portfolio / learning project. Refer to the source code for the currently implemented functionality.
